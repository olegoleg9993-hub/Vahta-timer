ВАХТА — СБОРКА APK ЧЕРЕЗ GITHUB

1. Откройте https://github.com/signup и создайте бесплатный аккаунт.
2. Создайте новый репозиторий: https://github.com/new
3. Название: vahta-timer. Выберите Public и нажмите Create repository.
4. Загрузите В САМЫЙ КОРЕНЬ репозитория всё содержимое этого архива.
   Файл settings.gradle.kts должен находиться сразу на главной странице репозитория,
   а не внутри дополнительной папки ShiftTimer.
5. Откройте вкладку Actions и выберите слева «Собрать APK».
6. Нажмите Run workflow, затем ещё раз зелёную Run workflow.
7. Дождитесь зелёной галочки, откройте завершённую сборку.
8. Внизу страницы, в разделе Artifacts, скачайте «Вахта-таймер-APK».
9. Распакуйте скачанный ZIP. Внутри будет app-debug.apk — установите его.

Если GitHub сам запустит сборку сразу после загрузки, пункт 6 можно пропустить.
