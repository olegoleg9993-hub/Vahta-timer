# Вахта — таймер и зарплата

Первая нативная Android-версия приложения для обратного отсчёта до окончания
вахты и расчёта заработка в реальном времени.

## Реализовано

- начало и окончание вахты с точностью до минуты;
- месячная зарплата;
- расчёт по фактической продолжительности каждого календарного месяца;
- посекундный заработок на главном экране;
- итоговая сумма за весь указанный период;
- обратный отсчёт и прогресс вахты;
- виджет главного экрана с системным посекундным таймером;
- автономная работа без интернета и регистрации.

## Формула

Каждый отрезок периода внутри конкретного календарного месяца считается как:

`месячная зарплата × длительность отрезка / длительность календарного месяца`

Поэтому полный январь, февраль или сентябрь всегда дают одинаковую указанную
месячную зарплату, несмотря на разное количество дней.

## Сборка

Откройте корневую папку в Android Studio, дождитесь синхронизации Gradle и
запустите конфигурацию `app`. Минимальная версия — Android 8.0 (API 26).

Для релиза RuStore создайте собственный upload key и соберите Android App Bundle
через `Build > Generate Signed Bundle / APK`.
